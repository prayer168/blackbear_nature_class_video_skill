# 影片專案與正式交付結構

2026-10-11 使用者定案。本技能的正式交付使用此結構，取代舊的「輸出成品／影片、字幕、配音、腳本、封面、預覽、文件」配置；來源照片與影片保持原位。

## 一個主題、正片加三支 Shorts

每次完成一支主片後，接續規劃、剪輯並輸出三支內容各異的 YouTube Shorts，除非使用者明確略過。以主影片名稱建立專案根目錄，底下固定建立四個資料夾；每個資料夾各自包含製作前、製作中、製作後三階段：

```text
主影片名稱/
├─ 00 正片/
│  ├─ 製作前/（逐字稿.txt、分鏡表.md、參考資料/）
│  ├─ 製作中/（配音/、圖片與動畫/、螢幕錄影/、剪輯專案/）
│  └─ 製作後/（正式 MP4、上架文案.txt、最終逐字稿.txt、縮圖.jpg、字幕/、臉書宣傳/臉書貼文.txt）
├─ 01 Shorts/
│  ├─ 製作前/（短片腳本.txt、分鏡表.md、參考資料/）
│  ├─ 製作中/（配音/、圖片與動畫/、字幕/、剪輯專案/）
│  └─ 製作後/（正式 MP4、上架文案.txt、最終逐字稿.txt、縮圖.jpg、字幕/、臉書宣傳/臉書貼文.txt）
├─ 02 Shorts/
│  ├─ 製作前/（短片腳本.txt、分鏡表.md、參考資料/）
│  ├─ 製作中/（配音/、圖片與動畫/、字幕/、剪輯專案/）
│  └─ 製作後/（正式 MP4、上架文案.txt、最終逐字稿.txt、縮圖.jpg、字幕/、臉書宣傳/臉書貼文.txt）
└─ 03 Shorts/
   ├─ 製作前/（短片腳本.txt、分鏡表.md、參考資料/）
   ├─ 製作中/（配音/、圖片與動畫/、字幕/、剪輯專案/）
   └─ 製作後/（正式 MP4、上架文案.txt、最終逐字稿.txt、縮圖.jpg、字幕/、臉書宣傳/臉書貼文.txt）
```

三支 Shorts 各自選取正片中不同且完整的亮點，具獨立開場、重點與收尾；不要只把正片等長切成三段，也不要重複同一內容。以直式 9:16 製作並按當下 YouTube Shorts 官方規格設定片長；規格不確定或可能變動時先查官方說明。重新取景與裁切時保留主體、字幕和角色完整可見，不得把橫式主片直接硬裁成直式而切掉重要畫面。各支短片各自製作腳本／逐字稿、字幕、縮圖及完整上架文案，不套用正片文案。來源素材不足以支持三支不同短片時，先據實指出限制，再調整方案或詢問使用者，不虛構畫面和內容。

## 正式成片與時間戳

- 最終 MP4 直接放在各影片的 `製作後/`，不再套 `輸出成品/`。
- 主片：`主影片名稱_正式版_YYYYMMDD_HHMMSS.mp4`；Shorts：`Shorts_短片名稱_正式版_YYYYMMDD_HHMMSS.mp4`。
- 時戳為正式匯出完成時間，使用 `Asia/Taipei`；整理舊片不得把複製時間冒充原輸出時間。無法確認時在專案卡註明來源及使用的檔案修改時間。
- 重新輸出另存新時戳版本，不覆寫已交付成片；專案卡指出目前應上架哪一檔。預覽、粗剪與退役版本歸入 `製作中/剪輯專案/`，避免與現行正式版混用。

## 每支影片一份 YouTube 上架文案

`製作後/上架文案.txt` 為 UTF-8 純文字，包含完整可直接貼上的四個區段：

```text
【YouTube 標題】
本支影片的最終標題

【說明欄】
摘要、適用對象、主片實際章節、來源與必要製作說明、Hashtag

【標記 Tags】
以逗號分隔，去重複；總長不超過 500 字元

【置頂留言】
本支影片的重點與互動問題
```

不再要求另交 `YouTube標題.txt`、`YouTube說明欄.txt`、`YouTube標記.txt`、`置頂留言.txt` 或上架文案 MD。候選標題與編輯草稿留在 `製作前/`。Shorts 說明欄依該短片內容撰寫，不套主片章節；完整片連結未知時清楚保留待填欄位。社群宣傳檔與字幕仍可獨立存放。Facebook 貼文為每支實際完成影片的標準交付，存放於 `製作後/臉書宣傳/臉書貼文.txt`；依該片最終畫面、旁白及已核實資訊撰寫，可直接複製發布，不虛構內容或影片網址。此檔案只代表文案已準備好，不會自動發布；使用者明確略過時才不產生。

逐字稿獨立：`製作前/逐字稿.txt` 保留拍攝／配音原稿；`製作後/最終逐字稿.txt` 必須與實際成片一致，刪除未使用句子，純旁白不混入上架文案。英文逐字稿按需求另存。

## 自攝素材與既有專案相容

不搬移或改名原始素材。製作中可保存素材索引、授權、配樂、Flow 匯出、生成紀錄與剪輯時間線；影片副本按本支用途分類。每支主片完成後預設產生三支 Shorts 與各自上架素材；使用者明確略過時才只保留待製作目錄。

既有剪輯程式若依賴舊結構，可在 `製作中/剪輯專案/工具工作區/` 保留舊配置，核對後把正式影片歸入新結構。搬移既有交付檔案時先複製、比較大小與 SHA-256、更新路徑，再處理舊檔；保留歷史版本，不因技能更新自動刪除原專案。

沒有旁白或對話的影片，`製作後/最終逐字稿.txt` 註明「本片無口白」；不能憑畫面編造台詞。若有字幕文字但無口白，可另列畫面文字，清楚區分。製作前原稿只有存在時才保存，不捏造拍攝前腳本。

每支完成的正片與 Shorts 都建立各自的 YouTube 上架文案，供日後發布使用；建立文案不代表登入、上傳、排程或公開授權。其他需要加時間戳的交付檔案仍可沿用既有規則，`上架文案.txt` 與 `最終逐字稿.txt` 保持固定檔名，方便找取。
